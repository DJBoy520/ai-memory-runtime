# AI Memory Runtime - 需求说明书 (PRD)

**文档标识**：`DOC-AMR-01-PRD`  
**版本号**：`v2.2.0`  
**适用范围**：多智能体本地记忆与会话存储组件

---

## 1. 背景与目标

多智能体（Hermes Agent、OpenClaw、OpenCode、DSH、QwenWork 等）在同机协同或交替工作时，需要共享项目上下文与关键决策记录。本项目旨在提供一个本地运行的会话存储与语义检索组件，满足以下基础需求：

1. **会话流水审计**：本地留存各智能体的对话记录，便于调试、复盘与回溯。
2. **结构化记忆检索**：将提炼后的关键事实（配置、规范、决策）向量化索引，支持按需检索相关上下文。
3. **状态与版本管理**：支持记忆的更新与归档，降低陈旧信息的召回干扰。
4. **同机进程间通信**：采用本地 Socket 接口，避免额外的网络端口暴露。

---

## 2. 核心功能需求

### 2.1 记忆管理
- **语义检索 (`memory_search`)**：输入自然语言或关键词，返回相关度排序的记忆片段；默认过滤非活跃状态条目。
- **记录沉淀 (`memory_record` / `memory_create`)**：显式沉淀事实、决策或规范文本，支持长文本自动切片。
- **详情与溯源 (`memory_get`)**：根据 ID 查询记忆详情，并返回关联的来源会话与消息跨度信息。
- **状态流转 (`memory_update`)**：支持记忆更新、废弃或归档，保留版本变更记录。

### 2.2 会话流水持久化
- **会话摄入 (`memory_ingest_session`)**：支持批量接收会话消息并写入本地 SQLite。
- **幂等与去重**：基于 `(session_id, message_id)` 及内容哈希，避免重复写入。

### 2.3 数据一致性与对账
- **事务发件箱 (Outbox)**：本地数据写入与向量索引同步异步解耦，降低外部服务抖动的影响。
- **一致性检查**：提供定时检查脚本，比对本地数据库与向量索引的条目数量与状态。

---

## 3. 非功能性指标

- **通信安全性**：采用本地 Unix Domain Socket 通信，文件权限设为 `0600`。
- **输入防护**：限制单次请求体体积（默认 4MB 上限），防范异常输入。
- **配置持久化**：敏感信息收敛于本地配置文件，不提交至版本库。
